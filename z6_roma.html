Zadanie 6 - Okienka dialogowe, zmienne, konwersje

1) Rodzaje okienek

W JavaScript wyróżniamy trzy rodzaje okienek dialogowych:
Okienko alert - wyświetla okienko dialogowe z informacją i przyciskiem OK,
Okienko prompt - generuje okno, w którym użytkownik może wpisać wartość, zwracaną następnie do programu,
Okienko confirm - służy do tego, aby użytkownik coś potwierdził (OK zwraca true, Cancel zwraca false).

2) Konwersje liczb

Wczytanie zmiennej z użyciem prompt wykonywane jest jako ciąg znaków, dlatego aby wykonywać obliczenia, konieczna jest konwersja z ciągu znaków na wartości liczbowe:
parseFloat(zmienna) - konwersja zmiennej do typu float (liczba zmiennoprzecinkowa),
parseInt(zmienna) - konwersja zmiennej do typu int (liczba całkowita),
toString(zmienna) - konwersja zmiennej do typu łańcuchowego (tekstowego).

3) Przy nadawaniu nazw zmiennym należy przestrzegać pewnych zasad (trzy zasady):

Zasada 1. Nazwa zmiennej musi się zaczynać od litery, znaku "$" lub "_", może zawierać tylko litery (bez polskich znaków), cyfry oraz "$" i "_".
Poprawne nazwy: zmienna1, $wynik, _rozmiar, wynik1, Rekord, $_gracz.
Błędne nazwy: 1zmienna, wynik gry, wysokosc&szerokosc, wynik.rekord, &gracz, wysokość, imie+nazwisko.
Zasada 2. Wielkość liter ma znaczenie. Rekord i rekord to dwie różne zmienne!
Zasada 3. Nie wolno używać słów kluczowych JavaScript jako nazw zmiennych.

4) Typy zmiennych w JavaScript

W JavaScript nie definiuje się typów zmiennych tak jak w C++ - typ jest określany w trakcie przypisywania wartości. Podstawowe typy:
Number - typ liczbowy (liczby całkowite i zmiennoprzecinkowe),
String - typ tekstowy (łańcuch znaków),
Boolean - typ logiczny (true / false),
Null - pusta zawartość,
Undefined - typ niezidentyfikowany (zmienna bez przypisanej wartości),
Object - obiekt.
