Zadanie 4 - teoria JavaScript

1) Kiedy powstał JavaScript (podaj datę).
JavaScript powstał w 1995 roku; w grudniu 1995 został zaimplementowany w najnowszej wówczas wersji przeglądarki Netscape Navigator.

2) Dlaczego jest to język skryptowy.
Jest językiem interpretowanym - nie musi zostać skompilowany do kodu maszynowego, aby zobaczyć efekty jego działania. Wystarczy przeglądarka internetowa, która go obsługuje.

3) Gdzie jest wykonywany JS (klient lub serwer).
Po stronie klienta, czyli w przeglądarce internetowej użytkownika (przy użyciu Node.js może być też uruchamiany na serwerze).

4) Dlaczego jest JS to bezpieczne narzędzie.
Ze względów bezpieczeństwa JavaScript ma znacznie ograniczone uprawnienia dostępu do zasobów komputera, przy użyciu którego przeglądana jest strona.

5) Czy jest to język obiektowy, jeśli tak to dlaczego.
Tak. JavaScript wykorzystuje definicje obiektów, metod i zdarzeń, które opisują właściwości obiektów. Struktura obiektów jest określana przez DOM (Document Object Model). Można korzystać z gotowych obiektów i metod, tworzyć własne oraz modyfikować istniejące.

6) Wymień zalety JS:
Zaleta1: prostota - język relatywnie łatwy do opanowania, można zacząć go używać po kilku minutach nauki.
Zaleta2: ogromna popularność - w Internecie są miliony praktycznych przykładów.
Zaleta3: odciąża serwery i ogranicza ilość danych przesyłanych między serwerem a przeglądarką klienta.

7) Framework to:
rodzaj programu do tworzenia innych programów (aplikacji) w JS, np. Angular (Google) czy React (Facebook).

8) Do aplikacji mobilnych można użyć Framework
React Native - pozwala budować aplikacje mobilne na różne systemy operacyjne (cross-platform apps).

9) Aplikacje responsywne to:
aplikacje dostosowujące swój wygląd do rozmiaru ekranu urządzenia. JavaScript udostępnia metody pobierania bieżącego rozmiaru ekranu, a przy użyciu CSS i HTML można zmieniać rozmiar, ukrywać, zmniejszać, powiększać lub przenosić treści, aby wyglądały dobrze na każdym ekranie.

10) Przepisz linię kodu, pod nią wytłumaczenie jak działa ten fragment kodu
‹input type="button" name="przycisk" value="Nowa Strona" onclick="WinOpen(' ')"›
Wytłumaczenie: tworzy przycisk (input typu button) o nazwie "przycisk" i napisie "Nowa Strona". Po kliknięciu przycisku (zdarzenie onclick) wywoływana jest funkcja WinOpen(), która otwiera nowe okno.

11) Przepisz linię kodu, pod nią wytłumaczenie jak działa ten fragment kodu
window.open("obraz.html","okienko","toolbar=no,directories=no,menubar=no,height=280,width=160,top=200,left=200");
Wytłumaczenie: otwiera w nowym oknie plik obraz.html; okno ma nazwę "okienko" i parametry podane w trzecim argumencie:

toolbar=noukrywa pasek narzędzi (przyciski przeglądarki)
directories=noukrywa pasek katalogów (pasek łączy)
menubar=noukrywa pasek menu
height=280wysokość okna 280 pikseli
width=160szerokość okna 160 pikseli
top=200odległość okna od górnej krawędzi ekranu: 200 pikseli
left=200odległość okna od lewej krawędzi ekranu: 200 pikseli

12) Opisz następującą instrukcję window.close()
zamyka bieżące okno przeglądarki (np. okno otwarte wcześniej metodą window.open()).

Jak wyświetlić instrukcję, która ma tylko się wyświetlić, a nie wykonać:
Pierwsza możliwość: znak < zastępujemy kodem &lsaquo;, a znak > kodem &rsaquo;.
Druga możliwość: tekst umieszczamy w znaczniku textarea (<textarea> ... </textarea>) - jego zawartość jest wyświetlana jako zwykły tekst i nie jest interpretowana jako instrukcja.
